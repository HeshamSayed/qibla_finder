# تعليمات الخطوط

يرجى تنزيل خطوط Cairo العربية من Google Fonts ووضعها في هذا المجلد:

## الخطوط المطلوبة:
1. Cairo-Regular.ttf
2. Cairo-Bold.ttf
3. Cairo-SemiBold.ttf

## رابط التنزيل:
https://fonts.google.com/specimen/Cairo

## الخطوات:
1. قم بزيارة الرابط أعلاه
2. انقر على "Download family"
3. فك ضغط الملف
4. انسخ الملفات الثلاثة المذكورة أعلاه إلى هذا المجلد

بدون هذه الخطوط، سيستخدم التطبيق الخط الافتراضي للنظام.
